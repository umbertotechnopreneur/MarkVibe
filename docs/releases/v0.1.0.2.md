# MarkVibe 0.1.0.2

I created MarkVibe to read my local Markdown, add handwritten notes and export a useful
HTML or PDF copy without assembling a separate converter workflow.

This initial release includes Windows 11 **x64 and ARM64**:

- A development-signed MSIX bundle that selects the architecture automatically.
- Separate MSIX packages and self-contained portable ZIPs for either architecture.
- Local files/folders, last-document reopening and direct PDF saving.
- Paragraph ink with separate metadata/sidecars, pen/highlighter/eraser and undo/redo.
- Modern light/dark theme, colored SVG buttons and an About window.

For MSIX, keep the bundle, public `MarkVibe-Development.cer` and
`Install-MarkVibe.ps1` together. Open PowerShell as administrator in that directory
and run `./Install-MarkVibe.ps1 -TrustDevelopmentCertificate`, then open MarkVibe
from Start. This explicitly trusts the development certificate and installs for
the current user. [Microsoft documents this certificate requirement](https://learn.microsoft.com/en-us/windows/msix/package/sign-msix-package-guide).

For portable, extract the matching ZIP completely to a writable folder and open
`MarkVibe.Windows.exe`. Both formats include .NET; Microsoft Edge WebView2 Runtime
is required. `BUILD-INFO.json` records the build and `SHA256SUMS.txt` covers the files.

The packages were compiled, packed and signed. I have not run automated tests or
installed this version; installer acceptance is the next manual step. Earlier app
checks are recorded separately in the repository. No Store submission is included.
