# Browser capability notes

The viewer chooses actions by checking capabilities on this device. A browser name alone does not decide which workspace methods are available.

## Connected folders

A connected folder requires a secure context and a directory picker. The browser may remember a handle, but access can expire or be revoked. Reopening asks for permission through your action.

## Imported folders

An imported folder preserves the relative paths exposed by the file selector. Its contents are a selection for this session. Choose the folder again to refresh it.

If your device does not provide those relative paths, choose a documentation ZIP or select related files.

## Selected files and ZIP

Selected files are useful for a single page. Choose a missing linked page or image when needed; only the file you explicitly select is added.

A ZIP preserves its internal directory structure. Large, encrypted, linked or unsafe bundles are rejected with an explanation.

## Privacy and local access

The app reads the files you choose in your browser. Settings and, when supported, a connected folder handle may be stored on this device. The viewer does not upload documents.

For handwritten annotations, export a PDF and use your preferred PDF application.
